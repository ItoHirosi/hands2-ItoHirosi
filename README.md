# GitHub勉強会 第2回 ハンズオン用リポジトリ

このリポジトリは、GitHub勉強会(第2回)のハンズオンで使う練習用です。
ブランチ、プルリクエスト(PR)、レビュー、ブランチ保護を体験します。
自由に編集して、壊してしまってもかまいません。

## 構成

| ファイル | 使う場面 |
| --- | --- |
| `docs/faq.md` | WS1:ブランチを作って編集し、PRを出して、レビューする題材 |
| `docs/team-rules.md` | WS4:自分たちのチームの運用ルール案を書く |
| `.github/pull_request_template.md` | PRを作るときの記入欄(自動で入ります) |

## 使い方

- 手順は、配布された「第2回ハンズオン手順書」に沿って進めます。
- 手順書の指示があるまでは、`main` ブランチを直接書き換えないでください。
